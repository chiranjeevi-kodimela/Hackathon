# RiskLens frontend

The React dashboard is served by Vite and connects to the RiskLens Express API.
Install dependencies from the repository root with `npm install --prefix
frontend`, then run `npm run dev` from the repository root. The default API
base URL is `http://localhost:5000/api`; set `VITE_API_URL` to use another
backend.

Run `npm run lint` and `npm run build` from this directory, or use the matching
root-level npm scripts.
